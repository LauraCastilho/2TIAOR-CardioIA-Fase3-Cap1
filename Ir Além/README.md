# Ir Além – Fase 3

As atividades opcionais "Ir Além" desta fase não foram desenvolvidas nesta entrega:

- **Ir Além 1:** comunicação automatizada com API REST em Python e envio de e-mail em caso de alerta.
- **Ir Além 2:** IA em séries temporais de saúde, comparando regressão logística com uma rede neuromórfica (LIF ou FHN).

O fluxo do Node-RED da entrega principal já isola os eventos de "novo alerta crítico" em uma saída própria. Esse é o ponto onde uma automação de e-mail poderia ser conectada em uma evolução do projeto.
